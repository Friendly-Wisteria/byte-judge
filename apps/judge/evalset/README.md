# 評価用テストセット

プロンプトやモデルを変えたときに、良くなったのか悪くなったのかを測るための仕組みです。
**入力内容を保存しない方針のまま改善を回すために必要**です。利用者の入力を集められない以上、
こちらで用意した固定の入力で測るしかありません。

## データ本体はリポジトリに含めていません

`cases.toml` は `.gitignore` 済みです。

危険側は合成データですが、**よくできているほど募集文のテンプレートとして使えてしまいます。**
「実在の闇バイト求人を公開リポジトリに置くとテンプレート集になる」という懸念は、
合成データでも同じように成り立つため、データ本体は公開する成果物から外しています。

このディレクトリのコード（`dataset.py` / `metrics.py`）と、この README はコミットします。

## 使い方

```bash
# API を叩かず、構成と費用の見積もりだけ確認する
uv run python manage.py evaluate_prompt --dry-run

# 実行（費用がかかります。実行前に確認が入ります）
uv run python manage.py evaluate_prompt

# カテゴリを絞る／件数を絞る
uv run python manage.py evaluate_prompt --category obvious --limit 3

# 結果を JSON でも残す
uv run python manage.py evaluate_prompt --json /path/to/result.json
```

`VIEW_TEST_MODE=True` のままだと固定サンプルが返って評価が意味を失うため、
コマンド側で実行を止めます。

**手動実行を前提にしています。** CI で毎回走らせると、実行のたびに API の費用が出ます。

## カテゴリ

| category | 内容 | 危険側 |
|---|---|---|
| `obvious` | 明らかな闇バイト（隠語・高額報酬・秘匿アプリ誘導などが揃っている） | ○ |
| `disguised` | 一見普通だが危険（表面上は正規求人に見えるが、実態が犯罪加担） | ○ |
| `legitimate` | 普通の求人（事業者情報が揃っている） | |
| `gray` | グレー（判断が難しい、情報が不足している） | |

`obvious` と `disguised` が偽陰性率の分母になります。

## 書き方

`cases.toml` を次の形式で作ります。

```toml
[[case]]
id = "obvious-01"
category = "obvious"
# 挙がっていてほしい根拠のキーワード（シグナル理由の妥当性を測るのに使う）
expect_signals = ["高額報酬|高すぎる報酬", "秘匿アプリ|Telegram"]
note = "任意のメモ"
text = """
（募集文の本文）
"""
```

- `id` は重複させないでください。
- `text` は実際に貼り付けられる形（SNS の投稿や DM のスクショを書き起こした形）で書きます。
- **危険側（`obvious` / `disguised`）は必ず合成データにしてください。** 実在の募集文を
  持ち込まないでください。
- `legitimate` は実在の求人を使って構いませんが、**事業者名・所在地・電話番号は伏せてください。**

## 指標

単純な正解率は見ません。正解率は、最も重い失敗を他の成功で薄めてしまうためです。

1. **危険求人の見逃し率（偽陰性率）— 最重視。**
   危険を伝えるべきケースのうち、画面上は危険が伝わらなかったものの割合です。
   **「危険な兆候なし」と「情報不足」の両方を見逃しに数えます。**
   利用者から見れば、どちらも警告が出ていない状態だからです。
2. **グレー求人への判定の安定性。** 同じ入力を繰り返して、判定がぶれないかを見ます。
   比べるのは**画面に出るラベル**です（内部の判定値が同じでも、`has_enough_info` が
   ぶれれば利用者の見るものは変わるため）。既定ではグレーだけ3回実行します。
3. **シグナル理由の妥当性。** `expect_signals` のキーワードが、挙がったシグナルの
   文中にあるかを見ます。同じ根拠でもモデルの言い回しは揺れるため（「高額報酬」と
   書くとは限らず「高すぎる報酬」と書くこともある）、`"A|B|C"` のように `|` 区切りで
   言い換えを並べられます。どれかに当たれば拾います。**キーワードの照合にすぎず、根拠の質そのものは測っていません。**
   取りこぼしに気づくための目安として使ってください。

参考値として、「明らかな闇バイトを要注意止まりにした割合」と「普通の求人を危険と
判定した割合（偽陽性）」も出します。偽陽性は利用者を正規の仕事から遠ざけますが、
偽陰性ほど重くはないという位置づけです。
